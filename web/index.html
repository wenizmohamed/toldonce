Tell your coding agent once.

ToldOnce turns every correction into a lesson in a Relate graph, linked to the projects, tools and tasks it covers. Before the agent acts, it recalls the lessons that connect to what you asked. This page runs the real Relate engine in your browser (WebAssembly) on the demo store, with the same Cypher the CLI uses.
